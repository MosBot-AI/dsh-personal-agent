## Implementation

- The native bundle provides `ctx.dshpa.host`. Its adapter creates and resumes native handles and checks the native session flush result. The DSH CLI and Cordis retain runtime and lifecycle ownership.
- The [agent](../../tests/contracts/host.spec.ts) and [schedule](../../tests/contracts/schedule-host.spec.ts) contracts start the published CLI with temporary named profiles and scripted local models. They read back the native JSONL session log and restart the CLI using the same test home. Each profile and its data are removed after the test.
