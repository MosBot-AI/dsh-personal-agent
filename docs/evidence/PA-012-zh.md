## 实现边界

- 经过认证的所有者可在本地 Web 收件箱显式记住、搜索、查看、更正和遗忘。每次操作使用准确的单一 Profile、项目或任务范围。界面显示来源回执、修订、置信度和有效期，并分别展示已确认和推断记录。自动提取处于关闭状态，外部知识库保持只读。
- 独立的 SQLite 记忆提供者保存事实内容，支持归一化搜索、修订检查、原子替代、墓碑及版本 1 快照导入导出。导入失败时，目标范围保持原状。
- 模式 009 的 WorkStore 账本保存来源回执、修订、状态、摘要哈希和可重放的命令回执。更正或遗忘先隐藏旧记录，再调用提供者。核心仅在固定的提供者精确回读后确认完成。如果同一修订的原始内容不一致，操作继续等待。可用相同的认证命令和载荷重试待完成变更。
- 读取时重新核对范围、权限、来源和当前账本状态。提供者的旧副本无法展示已替代或遗忘的内容，即使读取在排除生效前已经开始。显式个人记忆与 Worker 自动上下文和原生压缩摘要分开。
