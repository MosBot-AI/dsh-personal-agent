## Implementation

- The scoped inference ledger shares quota by owner, provider account and bucket in the same WorkStore. It distinguishes local rate windows, provider cooldown, hard exhaustion, and unknown or stale observations. Bounded admission under unknown telemetry requires configured request and token limits. An authenticated provider reset can clear durable exhaustion.
- Quota occupancy, the one-use inference claim and Core's spend reservation commit in one SQLite transaction. A pre-dispatch denial records its cause without consuming quota or creating a spend reservation. Schema 13 keeps a private v12 backup on upgrade.
- The trusted native executor accepts one approved input in a fresh, private DSH Session for each inference. It uses the existing Task and verifies authorization, capabilities, budget and confirmed effect receipts. The replacement receives freshly assembled authorized evidence. The prior output and replay state stay with the original Session, and the executor denies executable tool calls.
- Fallback follows the configured order, exact destination grants, attempt and switch caps, and a cycle check. Hard spend denial permits only an independently admitted zero-cost route. Resource waits persist on the original Task. An explicit continuation checks its exact reference and deadline and can retry the same deployment with a new request series. Core owns the retry decision, with one dispatch per attempt and zero gateway retries at this boundary.
- A partial or lost stream stays interrupted. Cold open retains uncertain charges and the one-use request history. An exact, verified fee readback can settle the original reservation. A live fallback waits for native Session flush and teardown.
