## Implementation

- The public contracts carry versioned deployment and policy pins, account and quota identities, capability and disclosure scope, declared pricing, and explicit effort mappings. Decisions and inference attempts carry the same Task fence and separate request-series identities. Attempt records retain reservation and usage references.
- The native adapter validates the deployment, policy, quota and attempt binding, resolves the exact DSH model metadata, and selects the route in unpublished Agent setup. The published native loop captures the model and effort before prompt assembly. Each admitted stream matches the captured route, effective effort, output cap and authorized capabilities. Core remains responsible for route authority and budget claiming, including each retry.
- A reroute gets a fresh native Session and request series under the same business Task. The new Session starts with authorized input and an independent request header. The adapter uses the existing DSH model selection and request-series APIs.
