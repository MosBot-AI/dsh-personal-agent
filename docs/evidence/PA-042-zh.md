## 实现

- 限定范围的推理账本在同一 WorkStore 内按所有者、提供者账户和额度桶共享配额。它区分本地速率窗口、提供者冷却、硬额度耗尽，以及未知或过期观察。未知遥测下的有限准入要求配置请求和 token 限额。经认证的提供者重置可清除持久耗尽状态。
- 配额占用、一次性推理声明和 Core 费用预留在同一 SQLite 事务内提交。派发前的拒绝会记录原因，且没有配额占用或费用预留。升级到模式 13 时保留私有 v12 备份。
- 可信原生执行器每次推理在全新的私有 DSH Session 中接受一次精确获批输入。它沿用原 Task，并核对授权、能力、预算和已确认效果的回执。替代请求收到重新组装的经授权证据。旧输出及回放状态留在原 Session，执行器拒绝可执行工具调用。
- 回退遵循配置顺序、确切的目的地授权、尝试及切换上限，并检查循环。硬预算拒绝只允许另行通过准入的零费用路由。资源等待保留在原 Task 上。显式继续会核对确切等待引用和截止时间，也可用新请求序列重试同一路由。Core 负责重试决策，此边界内每次尝试只派发一次，网关重试数为零。
- 部分或丢失的流保留中断状态。冷启动保留不确定费用和一次性请求历史。经核实的精确费用回读可结算原预留。实时回退会等待原生 Session 刷新并退出。
