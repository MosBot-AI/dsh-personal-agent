## 实现

- 路由策略在为 Task 评分前，按能力、上下文、数据范围和 Core 准入筛选精确配置的部署。Core 提供当前目的地授权、账户可用性、配额及预算。确定性估计器使用任务和阶段信号，包括工作范围、冲突证据及验收复杂度。
- 版本化自动规则按档位选择模型池与逻辑推理强度。低置信度采用已配置的保守下限。固定路由保持绑定，每任务覆盖要求所有者授权和符合策略的固定引用。自动策略可显式允许省略不可用强度。显式强度选择要求有效映射。
- 可选语义估计接收结构化信号，并使用独立的输入、输出、费用和截止时间限制。Core 准入入口占用预算并对 Task 和阶段键去重。策略将每次估计限制为一次派发回调，丢弃迟到或无效的结果，并在选定路由前重新核对准入。
- 升级需要同一 Task、尝试、策略及验收摘要下的可信质量结果。它保留已批准的要求、核对权威切换次数，并要求同一部署内的实际推理强度上升。缺输入或权限时进入等待。
