2026-11-16 在 Debian 13 x86-64 上对 dshpa main `eb10c69e3a137f82efe3434d467b1777b326be71` 进行评估，使用 Node.js 24.14.1 和 DSH 0.2.2-rc.1。在干净的检出目录运行 `pnpm check`，类型检查、工作区构建、421 项非 E2E 测试及计划校验通过。17 项协调测试通过。下面的原生宿主及提供者证据会注明与该检出版本不同的测试环境和产物版本。

原生 Web 和常驻宿主测试在私有 D-Bus 会话中使用 Chromium 156.0.8078.79，通过全部 21 项用例。来源为 `b94773c1b0370335e3a3b8031d212673b54702a5` 的三份保留 Alpha 归档通过校验和核对，以及打包启动、移除和重新安装测试。
