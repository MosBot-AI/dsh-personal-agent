## 集成决策

两个已评审文件树在四个文件中冲突：`packages/personal-agent` 下的 `src/client/inbox.tsx`、`src/inbox/host.ts`、`src/inbox/service.ts`，以及 `tests/client/inbox.spec.tsx`。只选一侧会移除草稿控件、桌面控件或其中一条验收路径。候选保留两组界面及测试，并要求两种运行时都排空后再关闭存储，启动失败清理也如此。

所有者结果验收保留不同要求：配置项目中的草稿任务必须走已有的精确效果／回执核验路径；本地或获租约的桌面任务必须先释放原生 Worker，也不能绕过必需回执。所有验收仍要求当前策略、封存产物及没有未结算效果。跨类型启动会被拒绝。现有 schema v16、手机审批、媒体、模型路由和预算检查均保留，未新增数据库迁移或调整编号。

新增原生同宿主回归同时启用已评审的 GitHub 草稿路径和真实隔离 Chromium。测试先挂起浏览器就绪请求，在浏览器仍执行时，准备、批准、派发、回读并验收另一个草稿任务。页面放行后，浏览器保存自己的值，其结果也可以被验收。尝试把已准备草稿转为桌面工作会被拒绝；在运行中的浏览器任务上准备草稿也会被拒绝。此用例的 GitHub 提供者是受控夹具，因此不构成真实 GitHub 连接器验收。
