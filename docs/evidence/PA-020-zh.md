## 已实现边界

- 已认证所有者在今日选择至少两个不同的已验收任务结果后，可提议项目范围内的 Markdown 模板。不可变版本保存准确的任务版本和产物版本、内容摘要、必填文本字段、Markdown 输出和 `render-markdown` 能力。样例产物保留在原任务中。模板和留出样例由所有者编写。
- 留出样例使用单独的已验收任务产物和显式输入。测试不能和样例使用同一任务，也不能沿用样例的输出字节。评测渲染每个测试，并将输出哈希与已验收产物的摘要比较。审批固定版本摘要和当前启用状态的版本号，并要求所有测试通过。
- 所有者显式运行已启用的版本。渲染器仅对有长度限制的字符串执行一轮替换，并以字面文本返回本地 Markdown。技能没有工具、插件、调度、通知、记忆或模型调用路径。接受和纠正按版本计数。重发运行请求时核对版本、操作 ID 和输入摘要。只要证据仍有效，已批准的旧版本可用于回滚。
- 查看、评测、启用、回滚和复用都会重新核对确切的验收记录和产物、来源排除规则以及当前来源授权。证据失效后会隐藏受影响的规格并阻止使用。私有工作库保存版本中的留出样例输入、证据引用和反馈。新运行的输入仅保存摘要，结果文本留在响应中。模式 012 保留先前记录并创建仅所有者可读写的 v11 备份。
