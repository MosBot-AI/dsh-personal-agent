## 设备与回放

- WorkStore 生成与所有者和资料范围绑定的五分钟一次性配对码。注册成功时，以独立的三十天凭据摘要原子替换配对码摘要。数据库保存摘要和设备元数据。撤销或过期后，下次检查就会移除设备权限。备份恢复会清除恢复副本中的旧待配对和已注册凭据。
- 独立于传输层的事件源对每次快照和回放进行鉴权。它读取现有 WorkStore 中关联会话的任务，在范围内的游标后回放最多 128 条已提交事件。游标缺失、超出范围或过期时要求获取新快照。事件包含任务 ID、版本、状态和时间。快照省略会话标识、来源目的地、私有约束及产物。
- 固定版本的 DSH Web 连接将浏览器凭据映射为共享的 owner Peer。精确 Fetch 路由要求这个 owner Peer。现有收件箱还会将审批绑定到精确的客户端、设备和会话。这些边界决定了独立的移动设备接入路径和显式审批移交。 [固定宿主证据](host-compatibility-zh.md) · [原生访问契约](https://github.com/deepseek-ai/deepseek-harness/blob/fcc0ad462172522aaf5c93a7b2e01f6b9f0b0159/packages/api/remote-access/README.md)

## 移动 HTTP 与 Web

提交 `d833b4a21a49c56641ae1cda2a021d87b4cd76b6` 将账本与事件源接入可选的回环 HTTP 监听。独立 HTTPS 源地址由操作者的反向代理终止 TLS。上游校验 Host、Origin 和 Fetch Metadata，配对设置独立的 Secure、HttpOnly、SameSite=Strict Cookie。原生本机所有者通过待办面板生成配对码并撤销设备。

独立的响应式页面读取限定范围的快照并订阅 SSE。超出窗口的游标会要求获取新快照。事件流每次轮询都重新核验设备，设备撤销后关闭。移动监听提供自身的静态资源、配对、快照、事件及已分配审批路由。 [配置方法](../../README-zh.md#启用移动任务视图)

## 移动精确审批

提交 `9373a93dd183b9a1ecba14adc816e4134b3845dc` 加入向单个已注册设备移交审批的版本约束，以及由原所有者客户端撤回审批的能力。WorkStore v15 分别保存原始审批绑定与被分配的答复方。手机将预期版本、摘要及批准或拒绝的决定提交给现有精确动作门禁。门禁核对移动授权的设备注册状态，协调器仍对原动作最多领取一次。SSE 审批提示省略预览。已认证页面通过独立请求读取精确审批卡片，并提供 Web 应用清单。

## 验证

2026-11-08（Asia/Shanghai）在本机运行。七个 PA-022 服务用例使用临时 SQLite WorkStore，覆盖一次性注册、拒绝跨资料范围访问、仅保存凭据摘要、过期、撤销已绑定身份、备份恢复、从 v14 升级到 v15 后保留凭据、重开后在范围内回放及过期游标回退。这些是进程内服务测试。

- `pnpm check` 通过了 48 个测试套件中的 285 项测试。
- `pnpm test:mobile` 通过两个原生 DSH Web 集成用例。第一个以预期的代理请求头向隔离的回环移动监听发送真实 HTTP 请求，验证本机所有者配对、拒绝操作员、拒绝跨源及其他 Host、Cookie 属性、本机和移动端相同的任务 ID 与版本、SSE 回放及游标回退，以及撤销已打开的事件流。它也检查所提供的页面与浏览器脚本语法。第二个通过使用临时证书的隔离 TLS 反向代理发送真实 HTTPS 请求，验证被指定设备可见性、拒绝其他设备、拒绝旧版本与篡改摘要、拒绝外部 Origin、两次并发答复只产生一份授权，以及撤销设备后由本机撤回。它还回读了保持原样的会话来源目的地。
- 设置 `DSHPA_CHROME_PATH` 后，`pnpm test:mobile` 在 macOS arm64 的 Google Chrome 156.0.8078.80 上通过全部三个用例。第三个用例使用隔离的无头 Chrome profile 和宽度为 390 CSS 像素的移动视口。Chrome 提交配对表单，保存 Secure、HttpOnly、SameSite=Strict Cookie，解析 Web 应用清单，并在完整刷新后保持配对。浏览器渲染已分配审批并提交精确答复。断开本地 TLS 代理会清除任务和审批内容。重连会恢复当前任务与待审内容，撤销设备会使页面回到配对状态。测试固定信任临时证书，Cookie 请求头由浏览器管理。
- 三个委派动作门禁用例使用受控连接器，验证精确动作只交接一次，以及在设备注册撤销、审批过期或任务取消后拒绝。HTTP 夹具记录审批答复，外部动作由测试环境隔离。
- 现有原生 Web 流程套件通过 10 个用例，常驻宿主套件通过两个用例。这些检查覆盖存储变更后的宿主回归。
- `python3 scripts/check_plan.py`、12 个协调测试及 `git diff --check` 通过。

2026-11-09，同一桌面 Chrome 移动视口用例在隔离 TLS 源地址上运行 `Page.getInstallabilityErrors`，返回零项安装条件错误。这项检查覆盖 Chrome 的安装条件。添加到主屏幕及启动仍待验收。

真实 Chrome 标签页切换验证了页面在隐藏时立即移除任务与审批内容。返回标签页后，页面保持空白，直到浏览器重新鉴权并获取最新数据。回归在标签页隐藏期间创建任务，验证返回后新任务与待审内容一同出现。
