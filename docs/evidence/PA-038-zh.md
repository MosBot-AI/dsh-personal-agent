## 已实现的边界

- `@mosbot-ai/dshpa-plugin-api` 版本 `0.1.0` 提供确切能力 API 版本 `1`、带类型的定义与提供方契约、严格的限定范围数据结构、配置 Schema 和生命周期操作。媒体、记忆、检索和创作工作流共用明确的目的地与模拟声明。
- 原生 `dshpaPlugins` 服务提供注册。核心私有注册表在启动前校验版本与配置，报告确切就绪状态，并明确选择已就绪的绑定。绑定含配置实例 ID、实现 ID、插件版本和配置修订。卸载先关闭准入，再等待已受理调用及迟到启动，最后排空并执行一次停止。
- 核心消费者在交接前核对可信授权，并在异步读取后再次核对披露权限。记忆命中须匹配确切规范记录、修订与来源。遗忘先记录核心排除项，再请求提供方删除。导入墓碑需要已确认的排除项，陈旧的活动记录继续受排除限制。
- 媒体提交校验模态、尺寸及已批准的产物引用。检查、取消和收集使用已记录作业及其原绑定。工作流子调用继承任务范围并受当前生命周期限制。可信媒体意图与已受理句柄回调独立于工作流输出保留对账证据。
- 测试工具包检查确切绑定行为及记忆快照往返。本地记忆和明确标注的模拟媒体示例是可由 DSH 分别加载的独立包。模拟提供方提供测试夹具元数据和生命周期行为。
