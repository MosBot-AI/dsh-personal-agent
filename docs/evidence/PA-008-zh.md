## 已实现边界

- 已构建的 Web 扩展通过 DSH 插槽加入 **待办** 主面板与侧栏入口。它使用 DSH 现有 Session 导航、对话记录和输入框。阻塞问题与确切审批预览排在已验收结果和日常任务之前。英语与简体中文文案来自成对的语言字典。
- 本地 Web Profile 启用后，宿主在原生 Connection 传输上挂载收件箱精确路由。它要求绑定回环地址并验证已认证的浏览器 Peer。测试区分了该 Peer 与具有相同主体类型的独立 API Peer。稳定且仅所有者可读的本地绑定限定项目、任务、产物和审批响应范围。请求体应用层上限为 512 KiB。
- 所有者创建项目，并将任务关联到已知的原生主 Session。启动使用明确配置的 Worker 路由和独立任务工作区。前台暂停、取消、引导与回答通过限定范围的确定性控制执行。继续和回答要求确切的等待或暂停状态及已知原生释放证据。未知运行时状态可见。连接变化时界面保留未发送或结果未确认的草稿，并刷新权威状态。
- 仅模型 Worker 可以把有界的就绪摘要封存为私有 Markdown 候选产物。所有者可下载确切字节，并在原生释放后明确接受产物。现有验收器会在提交完成前复核字节、产物范围、任务版本和当前所有者权限。精确审批卡使用持久化的摘要和版本。

此处为本地所有者界面。连接器路由仍由可信宿主组合，远程设备登记与完整重连安全归 PA-022。缺少原生释放或跨存储输入证据时，冷恢复归 PA-009。
