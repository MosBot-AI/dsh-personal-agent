## Implemented boundary

- The optional context profile checks that the live primary Session uses the two checkpoint-aware DSH plugins. Before native compaction or tool-result pruning, a scoped SQLite transaction captures the Task version, Attempt, objective, constraints, acceptance criteria, current wait, source-backed owner answers and evidence references. A checkpoint write failure blocks the native mutation. Managed compaction generates a local reference summary.
- The authenticated owner can look up exact Task, event or artifact references through the Web inbox. UTF-8 pagination checks current authority, revision and digest on every page. Bounded Chinese and English search uses the same scope checks. Forgetting and superseding evidence persist across restarts and filter derived checkpoint material.
- Worker context assembly uses the selected route's window, the native token estimator, a response reserve and section budgets. It preserves current instructions verbatim and journals the model-visible input with exact evidence IDs. Before dispatch, the native Worker checks the full request budget and revalidates retained input sources, including conservative source reconstruction for upgraded journals.
- Schema 008 adds checkpoints, exclusions and journal provenance. Migration creates an owner-private backup and preserves earlier Worker input records.
