## Implemented boundary

- Trusted adapters authenticate independently and bind exact configured source accounts. Intake normalizes events, hashes the canonical source payload, and deduplicates the source instance, external event ID, and opaque revision in SQLite. Altered payloads conflict. A prior version's source record retains its deduplication effect after upgrade.
- Explicit task references and exact versioned work subscriptions precede semantic assessment. Scope includes owner, profile, project, source instance, account, thread, and task. Multiple work matches require clarification. Context subscriptions record association only. Running work checks occurrence time against the Attempt start and subscription update, and an event wake checks the current wait boundary and exact reference.
- A routed input commits its source reference, task transition, journal entry, and route receipt together. The receipt includes the current native input status. Native pre-step admission rechecks the exact routed input, live subscription, and current authority. A released wait may resume the same Attempt and Session under an explicit trusted wake policy. Earlier admitted history remains in the native Session.
- A Worker handback binds the current Attempt, generation, task version and flushed input cursor. It returns the original event to assessment once. Worker report text stays inside the Worker boundary. Startup classifies interrupted pending routing, assessments, and handbacks without replay.
- Semantic assessment batches unrelated threads within one disclosure scope, rotates FIFO lanes fairly, caps outstanding work and applies a deadline. Late results are discarded. A slow adapter retains its slot until it settles. Each model decision is validated by event ID and can suggest a new task or request clarification for owner review. Query, redirect, and cancellation use the separate foreground path.
- Schema 005 preserves earlier source and Worker records. A v4 upgrade saves a private `.v4.bak` snapshot and retains the existing recovery fence. The local Web profile loads the optional routing model, and authenticated inbox operations manage subscription versions.
