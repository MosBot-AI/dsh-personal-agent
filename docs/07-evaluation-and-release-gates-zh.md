# 07. 验收场景与发布关卡

[文档索引](README-zh.md) · [English](07-evaluation-and-release-gates.md)

所有指标都是拟议发布目标，不是当前测试结果。此仓库目前只有计划；下面的测试文件由对应 PA 任务创建。确定性测试、真实 DSH 宿主、真实模型、真实外部服务和人工体验评估分别记录，不互相替代。

| E00 | 固定版本加载/卸载套件，缺依赖和错误版本 | 正常加载可释放资源；错误配置明确拒绝；无第二运行时 | PA-001、PA-002 |

| E13 | 手机断线重连、过期游标、撤销设备、跨渠道继续 | 同一任务和权限；快照补缺；旧设备不能读取或审批；原目的地保留 | PA-022、PA-023、PA-029 |

| E17 | 测试密码库保存/生成/登录/锁定，域名跳转及日志审查 | 秘密不进入模型、日志、截图/DOM/剪贴板；锁库后停止新使用；受限会话正确 | PA-032、PA-036 |
| E18 | 本机持续运行、关 UI、锁屏、睡眠、唤醒、网络断开 | 不依赖聊天窗口；按能力等待；唤醒核对；前台不被渲染饿死；不暗改电源配置 | PA-021、PA-031–035 |
| E19 | 实时 VNC 画面、只读用户伪造输入、接管/掉线/撤销 | 真实画面可见；服务端拒绝越权输入；接管无双控制；失效连接关闭；不暴露裸端口 | PA-036、PA-029 |
| E20 | 安全表单输入密码/密钥，重放、过期、断线、保存失败 | 秘密直达代理；返回引用；无明文日志/上下文；精确用途授权；临时状态失效 | PA-037、PA-032 |

## 2. 质量、响应和注意力目标

| 指标 | 初始门槛 | 测量方法 |
| --- | --- | --- |
| 权限/去重/取消关键不变量 | 已定义反例全部通过，零未解决严重缺陷 | 故障注入与并发测试；不宣称穷尽全部攻击 |
| 用户命令入队确认 | p95 ≤ 1 秒 | 记录机器/数据量；4 个受控后台作业、至少 1000 次命令；不含模型推理/外网延迟 |
| 无事件等待 | 不产生模型调用、不持有 Worker 槽 | 虚拟时钟下长等待及真实空闲观测 |
| 对话模型响应 | 报告 p50/p95、排队时间和模型时间 | 不把 API ACK 当作自然语言回答速度；先测后设模型目标 |
| 产物可用性 | 全部完成声明对应存在且可解析的产物/回执 | 文件内容、媒体解码、外部回读 |
| 确切记忆更正/遗忘 | 100% 规则符合 | 显式事实夹具；包含原日志仍存在时的重新检索 |
| 检索质量 | ≥ 80% 样例有相关且有来源的结果 | 至少 50 个中文/英文/混合查询，人工标注；未命中须诚实 |
| 端到端任务采纳 | 初始 ≥ 80% | 至少 30 次任务执行，六类场景各 5 次；人工 rubric，报告失败分布 |
| 主动建议有用率 | 初始 ≥ 70%，无越权副作用 | 至少 20 个获准展示的候选由用户判断；不足样本继续 observe |
| 非请求建议频率 | 默认 ≤ 3 次/天 | 跨渠道统一计数；明确提醒、必要审批和用户查询另计 |
| 注意力收益 | 报告人工干预次数及分钟，期望优于基线 | 相同任务、来源、模型和工具；无改善时限制主动范围 |
| 资源和费用 | 不超过已配置预算；未知项单列 | 调用前预留、结束后核算；报告峰值 RAM/VRAM/磁盘、token、实际费用 |
| VNC / GPU 性能 | 按设备报告，首版不捏造帧率和生成时长 | 测首帧、输入时延、断线恢复、渲染时长；另验证服务端撤销立即阻止新输入 |

基础 alpha 的六类质量样例为项目风险简报、资料研究、提醒、复盘、代码变更和文档/数据整理；桌面 alpha 另外加入图片创作和短视频，不能在媒体实现前要求通过媒体样例。模型 rubric 可辅助分析，但用户采纳不能由执行模型给自己打分。对比单前台 Session 与 Router/Worker 时保持相同资源预算；路由节省延迟但增加费用时必须如实报告。

## 3. 发布集合

- **基础 alpha（PA-028）：** E00–E12，7 天试用，至少一次真实模型→工具→写入→回读和取消/重启流程。仅供底座验证，尚不代表完整本机助手。
- **桌面 alpha（PA-035，默认首个完整产品目标）：** 基础 alpha + E14、E16–E21；本机电脑操作、VNC、密码库、图片及可播放短视频；至少 7 天常驻实测。
- **beta（PA-029）：** 桌面 alpha 回归 + E13、真实邮件/日历工作流及远程 VNC；7 天常驻远程使用。
- **v1（PA-030）：** E00–E21；14 天跨设备及语音试用。

图片或生成式视频能力必须在真实后端上单独通过。不具备视频模型时可交付明确标注的合成视频，但不得宣传生成式视频已完成。没有真实密码库、VNC 服务或硬件验证时，对应 track 只能写“模拟通过/未验证”，不能放行桌面 alpha。

## 4. 证据格式

每张 PA 任务写 `docs/evidence/PA-NNN.md`（实施时创建），字段如下：

```text
task / plan revision / implementation commit
host commit / OS / hardware / toolchain
changed paths and final behavior
commands actually run with exit codes
scenario IDs and fixture | native-host | live-model | live-provider | human-review
artifact paths / sanitized provider receipts
unexecuted checks and why
known limitations / migration and rollback
review result and next ready task
```

敏感素材、口令、令牌、完整邮件和屏幕录制不进入仓库。录制仅在显式启用且可脱敏时保存；凭据测试使用专用账号。发布报告链接证据，不复制秘密。
