# DSH Personal Agent 实施计划

[English](README.md)

**状态：设计与实施提案，并非可运行的发布版本。** 更新于 2026-11-07 UTC。本次文档工作开始时，仓库仅包含原有的 `LICENSE`。这些文档不代表所提议的插件、API、测试或客户端已经实现。

DSH Personal Agent 将 DeepSeek Harness 本身作为用户的核心个人智能体：由一个主智能体协调项目、任务、信息、提醒和委派工作。它是 DSH 原生插件组成的套件，而不是把 DSH 当作编程工具调用的外部助手。产品中不存在绑定现有 Bot、选择 Bot，或“不绑定 Bot 也能使用”的流程。

## 已确定与未确定的事项

- **已确定的产品方向：** DSH 是核心智能体；优先采用原生插件；管理项目、任务和信息；开放的连接器/MCP 边界；将持续对话与持久记忆作为设计目标；最终支持远程/移动端和语音访问。
- **已排除：** 对比选项 6 和 7，即绑定现有 Bot 及不绑定 Bot 的替代方案。渠道账户仍可能需要身份认证，但认证不用于选择个人智能体。
- **待选择：** Hermes 对比选项 1–5 和 8–10。其详细增强能力作为可选提案记录，不会默认纳入范围。
- **工程建议：** 下文的具体包拆分、SQLite 模式、传输形式、里程碑范围和性能关卡。这些仍需通过实现验证，也不能取代尚未作出的产品决策。

首个实施步骤是兼容性验证。已检查的当前 DSH 源码与 superagent 原型面向不同的 DSH 版本。原生 DSH 已有进程内取消和助手流式输出；计划不能将 SDK 接口的局限误认为运行时缺少能力。

## 交付边界

本次发布仅增加文档。不安装依赖、不启动智能体、不连接账户、不产生模型调用支出、不更改仓库许可证、不创建 GitHub Project，也不修改应用。本文有意不承诺里程碑日期和人员配置。实施应以验收证据推进，不能把完成设计标记为完成功能交付。
