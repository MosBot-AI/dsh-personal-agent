# 06. Agent 实施入口

[文档索引](README-zh.md) · [English](06-agent-execution-guide.md)

本计划已经给出可开始实现的工程基线。**本轮交付仅为方案，下面的 pnpm 命令和产品文件在 PA-001 等任务完成前尚不存在。** 不要直接启动任意模型/账户来“试一下”。当前真正可运行的是计划校验脚本。

## 1. 交接提示词

在未来明确要求 agent 开始开发时，可以使用：

```text
在本仓库实施 dshpa。先读 docs/README-zh.md、01、03、04、06、08、09，
再读取 docs/implementation-tasks.json。目标发布级别为 desktop-alpha。
检查工作区和上游 AGENTS.md；保护已有变更。按依赖选择首个 ready 的任务，
从 PA-001 开始，不跳到 UI、VNC 或 ComfyUI 集成。
对每个任务实现 target_paths 和 implementation_steps，创建 test_files，
执行适用的 validation_commands，并按 07 记录真实证据。
只把有代码及相应验证证据的任务标成 done；缺少凭据时独立开发继续，
实时关卡标 live-not-run。不得把计划文档、mock 或 skipped 测试当作真实产品完成。
保持 DSH 原生插件和本机常驻架构；不私自创建第二套编排系统。
```

这段提示词是未来实施模板，不是本轮已经执行的命令。目标范围可以缩为基础 alpha 或某张任务卡；发布和账号操作仍依具体实施请求确定。

## 2. 每次执行的流程

1. 读取当前分支、工作树和任务状态；核对 DSH/Superagent 固定 SHA。漂移则记录差异并重跑受影响的宿主契约，不复用未经验证的旧结论。
2. 选择目标发布集合内、依赖全部 done 的任务。若一个任务等真实资源，只标该任务 blocked，其他独立任务可继续。不要把任务 ID 数值顺序当依赖顺序。
3. 读取 `source_refs` 指向的原始代码/测试；`H:`、`S:` 映射见 manifest。所有目标文件是待实现路径，agent 可按需要细分，但必须更新任务卡与索引。
4. 将任务置为 in_progress；围绕行为实现，先固定输入/输出及失败语义。保持一个可评审变更，不把多个无关重构混入。
5. 执行必要的类型、构建和行为测试；真实 host 测试不能被模拟 host 替代。必要时更新模型可见输出快照和中英文文档。
6. 写证据文件，包含命令退出码、场景、产物、真实/模拟分类和未测限制；状态进入 review。
7. 检查安全边界、取消/恢复、数据生命周期、注意力成本和范围；修复缺陷后置 done。仅完成代码但关键验收缺失不能置 done。
8. 报告完成项、剩余阻塞和下一张 ready 任务。不要每次普通实现选择都要求用户重新批准。

跨会话交接保留任务卡和证据，不能仅依赖聊天摘要。提交计划不表示实施任务完成或应用版本已发布；项目 Issue 和发布属于独立操作。

## 3. 任务清单与机器契约

## 4. 工具链与验证命令

PA-001 固定工具链后创建下列脚本：`pnpm typecheck`、`pnpm build`、`pnpm test`、`pnpm test:contracts`、`pnpm test:recovery`、`pnpm test:e2e`、`pnpm check`。每个 task 的 Vitest 文件命令用于定向验证；不得用空测试文件使清单通过。live 测试必须显式启用并限定预算/测试账号，未启用时报告 skipped。

启动通过 `dsh --profile <已创建的配置档案>`；尖括号是占位符，不是可直接执行命令。M0 验证后把实际 profile 创建及加载命令写入安装文档。不要猜测新的 DSH CLI 子命令。

当前可执行：

```sh
python3 scripts/check_plan.py
python3 scripts/check_plan.py --check-sources
git diff --check
```

## 5. 决策与异常处理

内部接口和回滚方式可由 agent 按本计划确定。若要修改公开行为、增加依赖服务、自研密码库、切换权威数据库或改变发布集合，先写具体 ADR：问题、证据、选项、选定方案、迁移、风险和验证；不要用“后续优化”隐藏关键缺口。实际部署凭据、付费额度和用户授权不能由 ADR 自动生成。

某 upstream 引用失效，先在已固定版本查找；不能跳过源码核实。原型的测试用于理解语义，复制时保留许可并按个人场景重写不适用假设。最终交付包括代码、文档、测试和证据，不只包括一份 agent 自述。
